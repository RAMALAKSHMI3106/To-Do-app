# To-Do App

A simple To-Do List application built with **HTML, CSS, and JavaScript**. It allows users to add, complete, and delete tasks using **Local Storage**.

##  Features
- Add tasks
- Mark tasks as completed
- Delete tasks
- Local Storage support
- Responsive design


##  Technologies
- HTML
- CSS
- JavaScript
